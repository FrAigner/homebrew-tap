# Homebrew-Tap von FrAigner

```bash
brew install --cask fraigner/tap/playwright-workbench
```

Aktualisieren: `brew upgrade --cask playwright-workbench`

| Cask | Beschreibung |
| --- | --- |
| `playwright-workbench` | [Playwright Workbench](https://github.com/FrAigner/playwright-workbench) – Playwright-Tests schreiben und ausführen, ohne Node.js/npm zu installieren |

Die App ist nicht von Apple notarisiert; die Cask entfernt deshalb nach der
Installation das Quarantäne-Flag, damit macOS den Start nicht blockiert.
